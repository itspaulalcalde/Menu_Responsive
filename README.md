## VARIABLES CSS 
Las variables de css son elementos especiales para guardar valores de propiedas de CSS (usar en proyecto)

Se declaran en un pseudo-selectoe que se llama :root {} que se encontrara en la primera línea del CSS

Las variables se declaran con el nimbre que decidamos (que tenga sentido) precedido de --nombre-de-variable: valor;

Para llamar luego a esa variable usaremos la función 
var(--nombre-de-variable)
